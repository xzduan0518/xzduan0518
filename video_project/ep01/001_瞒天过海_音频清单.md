# 音频选型清单 · 第1集《瞒天过海》

> 岗位：3号 素材剪辑师 ｜ 规格：9:16 竖屏 ｜ 总时长 44s（00:00–00:44）
> 说明：本清单为古风 BGM 与环境音效的**选型建议 + 落点规划**，供剪映工程搭建与素材采购/授权核对。
> 授权要求：BGM 与音效须选用已授权可商用曲库（剪映「音频」素材库商业授权曲目，或已购授权的独立曲库），**禁止**使用未授权影视原声、网络下载曲目。片尾合规话术段落不得叠加喧宾夺主音效。

## 一、BGM 主轨（贯穿全片，单曲或分段拼接）

**推荐风格**：国风纯音乐，古筝 / 竹笛 / 埙 / 弦乐为主，低饱和、留白感强，避免打击乐过密。整体情绪曲线：**静（蓄势）→ 隐（暗流）→ 行（奔袭）→ 定（收束）**。

| 段落 | 时间 | 情绪 | BGM 处理建议 |
| --- | --- | --- | --- |
| 镜头1 全景 | 00:00–00:07 | 表面安宁、暗藏伏笔 | 古筝散音 + 竹笛长音起，音量偏低（-22dB 左右），稀疏留白 |
| 镜头2 中景 | 00:07–00:18 | 从容调度、隐秘推进 | 加入低音弦乐铺底，节奏微起，仍克制 |
| 镜头3 转场远景 | 00:18–00:30 | 夜航奔袭、张力上升 | 弦乐渐强 + 鼓点轻入（-16dB 左右），为本片情绪高点 |
| 镜头4 定格 | 00:30–00:38 | 庄重、成竹在胸 | 情绪回落，埙 / 钟磬点缀，留白收束 |
| 片尾落款 | 00:38–00:44 | 庄重收尾 | 主旋律再现后淡出（fade out 约 1.5s），给合规话术让出声场 |

- **备选方案**：若采用单曲，选 40–45s 区间内自带起承转合的国风纯音乐，剪映中裁剪至 44s 并在片尾做淡出；若分段拼接，在镜头切换点（00:07 / 00:18 / 00:30 / 00:38）做 0.3–0.5s 交叉淡化，避免硬切。
- **电平基准**：全程 BGM 低于人声旁白 8–12dB，确保旁白与片尾合规话术清晰可辨。
